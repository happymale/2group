# HEVEN 2026 MIT 시뮬레이터 판정 기준 (사용자 제공 규정 요약)

- 코드는 공개된 토픽·경로·코스 파일만 써야 합니다. 시뮬레이터 내부 파일이나 웹 화면 연결을 읽으면 안 됩니다. AI 도구와 공개 코드는 써도 됩니다.

## 점수
- 구성 만점 = (10 + 켠 항목 점수 합) × (1 + 세트 보너스 % + 도로 폭 단계 × 4%)
- 항목: 평행 주차 110, 후면 주차 110, 로터리 70, 장애물 1개 60, 장애물 3개 80, 저마찰 60, 경사 20, GNSS 음영 50, GNSS 노이즈 40, IMU 노이즈 60, LiDAR 노이즈 20, 조향 지연(기준 250 ms) 50, 구동·제동 지연(기준 75 ms) 30
- 세트 보너스 각 +6%: GNSS·IMU 노이즈 / IMU 노이즈 + GNSS 음영 / 후면·평행 주차 / 저마찰 + 경사 / 조향 + 구동·제동 지연 / 장애물 1개 + 3개
- 도로 폭 단계 0~5: 통로 폭 = 차폭 + 여유, 여유 2.5 m(0단계)에서 0.28 m씩 줄어 1.1 m(5단계). 통로 4.39 → 4.11 → 3.83 → 3.55 → 3.27 → 2.99 m. 장애물·주차 구간과 로터리는 좁히지 않음. 1단계부터 +4%씩.
- 모두 켜면 (10 + 760) × 1.36 = 1047.2점, 도로 폭 5단계까지 × 1.56 = 1201.2점.

## 감점·완주
- 감점: 벽·장애물·NPC에 닿으면 감점 사건. 구성 만점의 20%를 빼고 마지막 체크포인트로 복귀. 5번째 사건이면 실패(0점).
- 완주: 켠 미션을 모두 마치고 도착선을 지나면 완주. 제한시간 150초를 넘기거나 완주하지 못하면 0점.
- 완주 점수 = 구성 만점 × (1 − 0.2 × 감점 수) × (1 + (150 − 완주 시간) / 150). 완주 시간은 시뮬레이션 시간.
  → 감점 1회(×0.8)는 완주 시간 30 s 단축(×1.2 vs ×1.0)보다 손해가 큼. 여유가 속도보다 우선.

## 주차
- 성공: 차체 네 꼭짓점이 칸 안(여유 0.05 m), 방향 ±20°, 속도 0.05 m/s 이하로 3초 유지. (들어가는 방식은 규정에 없음 → 전진 진입도 조건만 맞으면 가능)
- 켠 주차를 하지 않고 다음 체크포인트를 지나면 실패 → 완주 불가(0점).

## 시도마다 seed로 바뀌는 것 (실제 값은 공개되지 않음)
- 저마찰·경사·장애물(2 m × 4.3 m)의 위치
- 주차 칸의 도로 방향 위치(같은 쪽에서 ±3 m)
- 로터리 NPC 속도(기준 3 m/s의 0.9~1.3배, 세 대 같은 속도)
- 모든 노이즈 크기와 두 액추에이터 지연(각각 기준값의 0.9~1.1배)
- 범위는 course.json(미션 zone, seed_scale)에 있음. 공식 시도는 모든 팀이 같은 seed.
- GNSS 노이즈: 백색 잡음(기준 σ 0.5 m) + 멀티패스형 오차(기준 σ 0.3 m, 상관시간 10초)

## 공식 시도
- 팀당 2회, 최고점. 같으면 주행 시간이 짧은 팀이 앞섬. 시도 사이에 코드·파라미터 변경 불가.
- 최종 점수는 소수 첫째 자리까지 표시, 순위는 반올림 전 점수로 비교.
